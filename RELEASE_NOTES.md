## Animated mode

`Animated` is placed immediately after `Funny` in the Multi Color menu. It retains the Funny per-pixel character while each lit LED smoothly transitions toward independently generated colors. The transition is continuous and does not use a short repeating animation loop.

No other clock function or parameter was intentionally changed for this feature.
